## Изображения

Все изображения — **собственные**, нарисованы для проекта и хранятся в исходном коде как векторные SVG: питомец (`src/ui/pet/PetSvg.tsx`), иконки товаров, целей и интерфейса (`src/ui/icons/Icon.tsx`), иконка приложения (`assets/icon-foreground.svg`), заставка. Растровые иконки и заставка сгенерированы из этих SVG (`npm run icons`). Сторонних картинок, фотографий и эмодзи-изображений нет.

## Звуки и музыка

**Звуки-сигналы** — аудиофайлов нет: они синтезируются в момент воспроизведения средствами Web Audio API (`src/platform/sound.ts`).

**Фоновая музыка** — два трека, которые команда предоставила как файлы (в имени префикс `ES_`, то есть каталог Epidemic Sound):

| Трек | Автор | Файл в приложении |
|---|---|---|
| Sensai Masopi Sky | DEX 1200 | `public/music/sky.m4a` |
| Metamorphosis | Laura Platt | `public/music/metamorphosis.m4a` |

Для встраивания оригиналы (MP3, ~230 кбит/с) перекодированы в AAC 96 кбит/с (`afconvert`), чтобы не раздувать приложение: 11 МБ → 4,7 МБ. Названия и авторы показываются в разделе для взрослых.

**Проверьте до сдачи и публикации.** ТЗ (п. 3.3) требует, чтобы все звуки имели право на распространение в составе приложения. Стандартные подписки на музыкальные каталоги обычно рассчитаны на видео и каналы; встраивание трека в приложение, которое раздаётся через магазин, может требовать отдельной лицензии. Я не могу этого подтвердить: сверьте условия вашей лицензии Epidemic Sound и сохраните документ о лицензии рядом со сдачей. Если права нет — замените файлы в `public/music/` и список `TRACKS` в `src/platform/music.ts` (например, на композицию с лицензией CC0 или собственную), либо отключите музыку по умолчанию (`music: false` в `DEFAULT_SETTINGS`).
