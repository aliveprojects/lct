# Разрешения, данные и удаление профиля

## Разрешения Android

**Приложение не запрашивает ни одного разрешения.** В `AndroidManifest.xml` проекта нет тегов `<uses-permission>`.

В собранном APK утилита `aapt2 dump permissions` показывает единственную запись — внутреннее разрешение `app.finni.kids.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`. Его автоматически добавляет библиотека AndroidX Core (для безопасной регистрации приёмников сообщений); оно принадлежит самому приложению, не показывается пользователю и не даёт доступа к данным или функциям устройства.

| Разрешение | Нужно? | Почему |
|---|---|---|
| `INTERNET` | нет | всё работает офлайн; шрифт и все ресурсы лежат внутри приложения |
| Камера, микрофон, геолокация, контакты, Bluetooth, хранилище | нет | обязательный сценарий их не использует |

Дополнительно в манифесте: `allowBackup="false"` (данные ребёнка не попадают в облачные резервные копии), `usesCleartextTraffic="false"`, отладка WebView выключена.

## Какие данные хранятся

Только на устройстве, в приватном хранилище приложения:

| Данные | Пример | Зачем |
|---|---|---|
| Игровое имя | «Ракета» | обращение в игре; настоящее имя вводить не просят |
| Имя и внешний вид питомца | «Финни», котик, мятный | игровой процесс |
| Монеты, накопления, покупки, история | — | игровой процесс и сохранение прогресса |
| Результаты заданий, очки роста | — | прогресс |
| Настройки (звук, анимации, размер текста, контраст) | — | доступность |

**Не собираются и не передаются:** реальное имя, телефон, e-mail, возраст, адрес, устройство, идентификаторы рекламы, геоданные, платёжные данные, сведения о семейном бюджете. Нет аналитики, рекламы, сторонних SDK и облачных сервисов. Поэтому согласие законного представителя на обработку персональных данных для обязательного сценария не требуется.

Поле «игровое имя» — свободный текст до 12 символов. В интерфейсе прямо сказано, что настоящее имя писать не нужно; данные не покидают устройство.

## Срок хранения и удаление

Данные хранятся, пока приложение установлено, и удаляются:

| Способ | Что происходит |
|---|---|
| Раздел для взрослых → «Удалить профиль» (с подтверждением) | профиль стирается полностью, приложение возвращается на первый экран |
| Раздел для взрослых → «Сбросить прогресс» (с подтверждением) | игра начинается заново, имя игрока и питомец остаются |
| «Сбросить тестовый профиль» | только тестовый профиль возвращается к исходному состоянию; игровой не затрагивается |
| Удаление приложения | удаляются все данные (резервных копий нет) |

Обращаться к разработчику не нужно.

## Защита ребёнка

- Внешних ссылок нет вообще (ресурсы для семьи названы текстом в разделе для взрослых, без гиперссылок).
- Нет чатов, обмена сообщениями, рейтингов, публикации контента.
- Нет рекламы, подписок, внутриигровых покупок и случайных платных наград. Игровые монеты нельзя обменять на деньги и призы — об этом сказано в интерфейсе.
- Раздел для взрослых отделён барьером (пример на умножение). Бонус взрослого ограничен 20 монетами в неделю и не имеет реальной стоимости.
