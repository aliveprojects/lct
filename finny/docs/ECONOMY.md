# Игровая экономика: формулы и правила

Все числа собраны в одном месте — `src/domain/econ.ts` (`ECON`). Игровая валюта — «монеты»: они не имеют реальной стоимости и не обмениваются на деньги или призы.

## Константы

| Параметр | Значение | Смысл |
|---|---|---|
| Стартовый подарок | 100 | при создании профиля |
| Карманные монеты | 70 | в начале каждой следующей недели |
| Подарок дня | 5 | раз в календарные сутки, без серий и штрафов за пропуск |
| Бонус от взрослого | до 20 за неделю, шаг 5 | раздел для взрослых |
| Шаг плана | 5 | шаг степпера |
| Показатель питомца | 0…100 | сытость, чистота и здоровье, настроение |
| Стартовые показатели | 60 / 60 / 65 | |
| «Просит заботы» | < 40 | меняется выражение мордочки и подсказка |
| Нижняя граница | 25 | показатели никогда не опускаются ниже |
| Снижение за неделю | −30 / −20 / −15 | сытость / чистота / настроение |
| Очки роста: пороги стадий | 0 / 8 / 20 / 36 | стадии 1 «Малыш», 2 «Подросток», 3 «Взрослый друг», 4 «Мастер копилки» |
| Мечта исполнена | +3 очка роста, настроение +40 | |
| Первый взнос за неделю (≥ 5) | настроение +6 | |
| Держался плана | настроение +8 в конце недели | |

## Баланс

```
баланс' = баланс + доход − расход − взнос в копилку + снятие из копилки
```

- Доходы: `Стартовый подарок`, `Карманные монеты`, `Подарок дня`, `Задание`, `Бонус от взрослого`.
- Любое изменение записывается в `ledger` с названием источника, суммой и балансом после операции.
- Отрицательный баланс невозможен: покупка или взнос при нехватке монет отклоняются (`NOT_ENOUGH`) без изменений.
- Накопления учитываются отдельно (по целям); сумма накоплений не входит в баланс.

## План и «конверты»

Ребёнок делит **баланс на момент подтверждения** на три направления: Нужное, Хочется, Копилка. Сумма не может превышать баланс; остаток — «запас».

```
остаток = баланс − (нужное + хочется + копилка)   // ≥ 0
осталось в конверте = max(0, план − использовано)
использовано: нужное = потрачено на нужное; хочется = потрачено на желаемое;
              копилка = отложено − снято (не меньше 0)
свободные монеты = баланс − Σ осталось в конвертах   // могут быть < 0, если ребёнок перерасходовал
```

После подтверждения план не меняется. Монеты, полученные позже, можно **добавить** в любой конверт (`topUpPlan`) из свободных монет. Траты на непредвиденные события в план не входят.

## Покупки

- Нужное: не блокируется планом, но перерасход отмечается в итогах.
- Хочется: если цена больше остатка конверта — отдельное подтверждение («Купить всё равно» / «Подумаю» / список желаний). Отказ и перенос не считаются ошибкой.
- Показатели питомца: `новое = min(100, старое + эффект)`. Если показатель уже ≥ 85, покупка помечается «почти не нужно».
- Нехватка монет: объяснение «не хватает N» и варианты — заработать, выбрать дешевле, список желаний, взять из копилки (для нужного), подождать.

## Награды за задания

Каждое задание задаёт награду за 1, 2 и 3 звезды (`rewards`). Выплата:

```
если новый результат лучше прежнего:  доплата = награда[новые звёзды] − уже выплачено
иначе: 0
```

Так повторять задание ради монет нельзя, но улучшить результат — можно.

Звёзды в заданиях-«проверках» (сортировка, расчёт): все ответы верны — 3 звезды; верно 60 % и больше — 2; меньше — 1. В остальных типах звёзды считаются по правилам самого задания (см. [карту контента](generated/CONTENT-MAP.md)). В любом случае ребёнок получает разбор, а на 1–2 звёздах — подсказку «Как исправить» и кнопку «Попробовать ещё».

## Накопления и срок цели

```
осталось = цена − накоплено
средний взнос = среднее значение взносов по прошлым неделям, где они были
                (если завершённых недель ещё нет — берётся текущая неделя)
срок (недель) = округление вверх(осталось / средний взнос)
```

- Снятия из копилки на средний взнос не влияют: срок отражает регулярность пополнения.
- Перед снятием показываются «накоплено: до → после» и «срок: до → после» (тот же средний взнос, но больше «осталось»); снять можно только после отдельного подтверждения.
- Взнос нельзя сделать больше остатка до цели; накопленная цель исполняется отдельным действием.

## Итоги недели и рост питомца

Три группы очков, вместе до **8** за неделю:

| Группа | Очки | Условие |
|---|---|---|
| **А. Нужное** | 3 / 1 / 0 | куплены и еда, и уход / что-то одно / ничего |
| **Б. План и факт** (0–3) | +1 | «нужное» потрачено (> 0) и не больше плана |
| | +1 | «хочется» потрачено не больше плана (0 — тоже хорошо) |
| | +1 | отложено не меньше плана копилки (план копилки > 0) |
| **В. Накопления** (0–2) | +1 | отложено за неделю не меньше 5 |
| | +1 | так же было и на прошлой неделе (регулярность) |

Очки группы Б даются, только если неделя не пустая (были покупки или взносы): подтвердить план и ничего не сделать — не решение.

```
очки роста' = очки роста + А + Б + В        // никогда не уменьшаются
стадия = наибольшая стадия, порог которой ≤ очки роста
```

В конце недели:

1. показатели питомца снижаются (−30 / −20 / −15), но не ниже 25;
2. если «нужное» и «хочется» уложились в план — настроение +8;
3. начисляются очки роста, обновляется стадия;
4. на новую неделю приходят 70 карманных монет, остаток баланса сохраняется;
5. если на неделю назначено событие — оно появляется на главном экране.

Экран итогов показывает каждую строку формулы с очками, статусом (иконка + слово) и подсказкой, как улучшить результат: так ребёнок видит, **почему** питомец вырос или что стоит поменять.

### Пример

План 35 / 25 / 30 при балансе 100. За неделю: обед (15), расчёска (7), мячик (12), в копилку 30. Итого: А = 3 (еда и уход), Б = 3 (нужное 22 ≤ 35, желаемое 12 ≤ 25, отложено 30 ≥ 30), В = 1 (30 ≥ 5, но это первая неделя). Очки недели — **7**. Остаток баланса 36 + 70 карманных = 106.

## Восстановление после неудачи

| Ситуация | Что видит ребёнок | Путь исправления |
|---|---|---|
| Не купил еду или уход | питомец просит заботы; строка итогов «Начни новую неделю с нужного» | купить на новой неделе, заработать в заданиях |
| Перерасход «Хочется» | «Больше плана… это не ошибка» | выбрать дешевле, отложить покупку в список желаний |
| Не отложил | «Даже 5 монет в неделю — уже привычка» | откладывать сразу после плана |
| Задание выполнено плохо | объяснение, «Как исправить», «Попробовать ещё» | повторить: доплатят разницу за лучший результат |
| Непредвиденная трата (неделя 3) | баннер «Питомец чихнул», объяснение, зачем нужен запас | оплатить из кошелька, заработать или взять из копилки |

Очки роста и накопленные монеты не обнуляются ни при каких ошибках. Питомец не болеет, не «умирает» и не стыдит ребёнка; единственное «плохое» состояние — просьба о заботе (голоден, хочет помыться, скучает).
