# Известные ограничения и план развития

## Ограничения прототипа

| Ограничение | Комментарий |
|---|---|
| Проверка на физическом устройстве не проводилась | сборка проверена на эмуляторе Android 14; перед сдачей нужен прогон на реальном телефоне с ОЗУ ≥ 3 ГБ по [TESTING.md](TESTING.md) |
| Требуется современный WebView (84+) | обновляется автоматически на устройствах с сервисами Google/RuStore/AppGallery; на «замороженных» устройствах интерфейс может отображаться некорректно |
| Учебный контент обновляется вместе с приложением | формат вынесен в JSON, но загрузки пакетов контента нет |
| Только русский язык | тексты собраны в `content/` и `domain/`, но не в таблицах локализации |
| Нет облачных резервных копий | сделано намеренно ради приватности; при удалении приложения прогресс теряется |
| Одна игровая неделя = один цикл «план → покупки → итоги» | привязки к реальному времени нет: ребёнок сам завершает неделю |
| Питомец рисуется программно (4 вида) | без анимированных сцен и озвучки |
| iOS-версия не собиралась | платформа Capacitor позволяет добавить её без смены стека |
| Не проверено с программой чтения экрана TalkBack | разметка ARIA добавлена, но живая проверка не проводилась |
| Исследование с детьми не проводилось | по ТЗ оно допускается только с согласия законных представителей |

## План развития

**Ближайшее (до финальной экспертизы)**
1. Прогон на физическом устройстве и заполнение отчёта в `docs/TESTING.md`.
2. Юзабилити-сессия с 3–5 детьми 7–11 лет (с согласием родителей) и корректировка текстов.
3. Проверка с TalkBack и системным масштабом шрифта 200 %.
4. Съёмка скриншотов и демо-видео (до 3 минут) для карточки RuStore.

**Продукт**
5. Больше заданий и тем (безопасность платежей, сравнение цен, подарки и общие траты) — только JSON-файлы.
6. Пакеты контента: загрузка новых заданий без переустановки (подпись и проверка целостности).
7. Больше питомцев, декораций комнаты, разблокируемых за исполненные мечты.
8. Семейный режим: печатный «отчёт для родителя» без отправки данных.
9. Планшетный двухколоночный макет и альбомная ориентация.
10. Озвучивание заданий для детей, которым трудно читать.

**Техническое**
11. Автоматический интерфейсный тест (Playwright/Espresso) обязательного сценария.
12. Проверка контраста и размеров касания в CI.
13. Локализация через таблицы строк.
