# Финни

Офлайн-приложение для Android, в котором ребёнок 7–11 лет растит питомца и учится обращаться с игровыми монетами: планирует неделю, делит монеты на **нужное**, **хочется** и **копилку**, копит на мечту и решает ситуации в заданиях.
Функциональный прототип по ТЗ Департамента финансов города Москвы («Виртуальный питомец: финансовая грамотность для детей»).

- **Без интернета, аккаунта, рекламы и покупок.** Разрешений Android не запрашивается. Данные хранятся только на устройстве.
- **Космическое приключение:** тёмное звёздное небо, светящиеся монеты, питомец-исследователь на своей планете.
- **Финни — и название приложения, и питомец-талисман.** Он встречает ребёнка; своего питомца ребёнок называет сам (по умолчанию предлагается «Финни»).
- **Фоновая музыка** из двух треков, отдельный переключатель в настройках. Лицензии на треки — см. — см. [docs/LICENSES.md](docs/LICENSES.md#звуки-и-музыка).
- **Игровая механика:** решение → понятное последствие → рост питомца. Ошибка — не наказание, а учебная ситуация с путём исправления.

## Быстрый запуск

Нужен только Node.js 22+.

```bash
npm ci          # зависимости
npm test        # 240 автотестов: экономика, покупки, накопления, задания, периоды, сохранение, случайные прогоны
npm run dev     # открыть http://localhost:5173 (в браузере лучше включить режим телефона 360×640)
```

### Собрать APK

Подробная инструкция — [docs/BUILD.md](docs/BUILD.md). Кратко:

```bash
./scripts/make-keystore.sh     # один раз: ключ подписи создаётся ВНЕ репозитория (~/.finni-release)
npm run release                # проверки → сборка → release/finni-1.0.0-release.apk и .aab
```

### Показать демонстрационный режим

1. Откройте раздел для взрослых (замок в шапке главного экрана → решить пример) → **«Включить демо-режим»**.
2. Пройдите шаги ТЗ вручную по [docs/DEMO-SCRIPT.md](docs/DEMO-SCRIPT.md) либо нажмите на плашку **«Демо-режим»** на главном экране → «Сыграть неделю автоматически».
3. Все задания в демо-режиме открыты сразу, недели и «подарок дня» переключаются без ожидания.
4. «Сбросить тестовый профиль» возвращает исходное состояние; игровой профиль ребёнка при этом не затрагивается.

### Проверить на устройстве

`node scripts/device-smoke.mjs` (нужны adb и подключённый телефон или эмулятор) устанавливает APK, замеряет запуск, проходит обязательный сценарий настоящими касаниями и сохраняет скриншоты в `store/screenshots/`. Подробности — [docs/TESTING.md](docs/TESTING.md).

## Состав репозитория

```
src/
  domain/       игровая экономика — чистые функции без интерфейса и хранилища
  content/      учебный контент в JSON: товары, цели, задания (tasks/*.json), события, словарик
  ui/           экраны, компоненты, иконки и рисованный питомец (SVG)
  app/          состояние приложения, навигация, окна, сохранение
  platform/     хранилище, звук, кнопка «назад» Android
tests/          автотесты (Vitest)
android/        проект Android (Capacitor)
docs/           сопроводительная документация
scripts/        сборка релиза, ключ подписи, иконки, документация, проверка контраста, тест на устройстве
assets/ store/  исходник иконки и материалы для карточки RuStore
```

**Чтобы добавить задание**, достаточно положить JSON в `src/content/tasks/` — код менять не нужно; см. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#добавление-контента).

## Безопасность репозитория

В репозитории нет паролей, токенов и ключей подписи. Ключ создаётся локально в домашней папке — `~/.finni-release/` (см. `scripts/make-keystore.sh`), Gradle читает его оттуда. Дополнительно `.gitignore` закрывает `*.jks`, `*.keystore` и `keystore.properties`.
