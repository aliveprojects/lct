# Веб-версия и нативная версия

Обе версии делают одно и то же, для одного и того же ТЗ. Разница — в том, как это устроено внутри.

| | Веб-версия (`../finny`) | Нативная версия (`nativeapp`) |
|---|---|---|
| Интерфейс | Preact в WebView (Capacitor) | Jetpack Compose |
| Язык | TypeScript | Kotlin |
| Движок | чистые функции TS | тот же движок, порт на Kotlin (действие → новый профиль + отчёт) |
| Контент | JSON | те же JSON-файлы |
| Питомец, иконки | SVG в DOM | те же SVG, рисует AndroidSVG |
| Хранение | SharedPreferences через плагин Capacitor | SharedPreferences напрямую |
| Музыка и звуки | HTMLAudio, WebAudio | MediaPlayer с аудиофокусом, синтез коротких сигналов (AudioTrack) |
| Программы чтения с экрана | через ARIA в WebView | нативные семантики Compose |
| Размер APK | ≈ 8 МБ | ≈ 6,5 МБ (R8 + сжатие ресурсов) |
| Запуск | ≈ 0,7 с (WebView) | ≈ 0,35 с |
| Работа в браузере | да: https://aliveapps.ru/finni | нет |
| Тесты | 240 (Vitest) | 73 (JUnit) + 18 проверок на устройстве |

## Что сохранено один в один

Экономика (старт 100, +70 в неделю, подарок дня +5, очки роста 0–3 + 0–3 + 0–2, стадии с 0 / 8 / 20 / 36 очков), тексты и объяснения, задания, события, цели, режим для экспертов с тестовым профилем, раздел для взрослых с проверкой примером, настройки доступности, вид «Космическое приключение».

## Чем нативная версия лучше

- Быстрее запускается и меньше весит, не зависит от версии WebView на телефоне.
- Нативная работа с TalkBack, системным размером шрифта, жестом «назад», клавиатурой и аудиофокусом (музыка ставится на паузу при звонке или другом плеере).
- Меньше «слоёв»: нет моста между JavaScript и Android.

## Что не перенесено

- Нет запуска в браузере. Демонстрация в вебе остаётся у веб-версии.
- Тест-набор веб-версии из 240 проверок заменён на 73 теста движка: они переносят все сценарные тесты и главный тест на случайных последовательностях (150 прогонов по 120 действий с проверкой закона сохранения монет), но не повторяют каждый из веб-тестов по отдельности.
