# Архитектура нативного приложения

## Слои

```
 Экраны (Compose)  ──►  Game (состояние)  ──►  Движок (domain)  ──►  Контент (JSON)
       │                     │
       │                     └─►  Storage (SharedPreferences)
       └─►  Ui (окна) · Nav (навигация) · Music / Sound
```

1. **Движок (`domain/`)** — чистый Kotlin без зависимостей от Android. Каждое действие — функция `(Profile, аргументы) → Outcome`: успех несёт **новый профиль** и **отчёт «что изменилось и почему»**, ошибка несёт объяснение и варианты выхода. Профиль копируется через JSON (`deepCopy`), поэтому исходный профиль никогда не меняется, а отклонённое действие ничего не портит. Все числа экономики — в `Econ.kt`.
2. **Контент (`content/`)** — предметы, цели, события, словарик и девять заданий лежат в JSON. Новое задание — новый файл в `assets/content/tasks/`, код менять не нужно (файлы находятся автоматически, проверяются `validateContent`).
3. **Состояние (`app/Game.kt`)** — единственный источник правды: `AppState` в Compose-состоянии. Профиль меняется только через `Game.act { профиль, контекст -> движок }`; успех сохраняется (с задержкой 120 мс, чтобы серия действий писалась одним разом; при сворачивании — сразу).
4. **Окна (`app/Ui.kt`, `ui/Overlays.kt`)** — «обещания» на корутинах: `Ui.confirm`, `Ui.report`, `Ui.sheet` приостанавливают вызывающий код, пока окно открыто. Долгие сценарии запускаются в `Ui.scope`, чтобы не обрываться, когда экран, с которого всё началось, уходит с экрана.
5. **Навигация (`app/Nav.kt`)** — стопка маршрутов (`/plan`, `/task/<id>`, `/create?step=1`); системная кнопка «назад» сначала закрывает окно, потом идёт по стопке, на корневом экране сохраняет прогресс и закрывает приложение.
6. **Экраны (`ui/screens`)** — по одному файлу на раздел; общие компоненты — `ui/Kit.kt`.

## Питомец и иконки

Питомец — параметрический рисунок: вид × цвет × украшение × стадия × выражение (4 × 4 × 7 × 4 × 5). `ui/pet/Pet.kt` собирает SVG из текста, AndroidSVG рисует его на канве Compose; разобранные рисунки кэшируются. Покачивание питомца — анимация Compose (`graphicsLayer`), она отключается настройкой «Анимации». Иконки — 48 SVG в `assets/icons` (контурные берут цвет текста, цветные — свои).

## Хранение и данные

Один ключ `state.v1` в SharedPreferences (JSON). Повреждённые данные не роняют приложение: копия уходит в резерв, игра начинается заново. Поля, которых нет в старых сохранениях, достраиваются значениями по умолчанию. Игровой и тестовый (демо) профили хранятся раздельно. Резервное копирование Android выключено, интернет и разрешения не нужны.

## Доступность

Все интерактивные элементы имеют описания для TalkBack (кнопки, шкалы «X из Y», звёзды, конверты плана), размер текста — «обычный / крупный / очень крупный» поверх системного масштаба шрифта, режим высокого контраста (чёрный фон, жёлтые действия), отключение музыки, звуков и анимаций. Цвет никогда не единственный признак: рядом всегда есть слово или значок.
