# Лицензии

| Компонент | Лицензия |
|---|---|
| Код приложения, рисунки питомца и иконки | как у остального репозитория (авторские, нарисованы для проекта) |
| Шрифт Rubik | SIL Open Font License 1.1 (файл `res/font/rubik.ttf`) |
| AndroidSVG | Apache License 2.0 |
| Jetpack Compose, AndroidX, Kotlin, kotlinx.serialization | Apache License 2.0 |
| Фоновая музыка: «Sensai Masopi Sky» — DEX 1200, «Metamorphosis» — Laura Platt | Epidemic Sound — см. ниже |

**Музыка.** Файлы предоставлены заказчиком из Epidemic Sound. Подходит ли лицензия для встраивания треков в приложение (и для его публикации в RuStore), нужно подтвердить по условиям вашей подписки: обычно лицензия покрывает публикацию контента на каналах, но не распространение файлов как части программы. Если лицензии недостаточно, замените два файла в `app/src/main/assets/music` и список `TRACKS` в `platform/Music.kt` — больше ничего менять не нужно. Авторы указаны в разделе для взрослых.
