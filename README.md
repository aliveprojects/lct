# Финни

Офлайн-приложение финансовой грамотности для детей **7–11 лет**: ребёнок растит питомца и учится обращаться с игровыми монетами — планирует неделю, делит бюджет на **нужное**, **хочется** и **копилку**, копит на мечту и решает учебные ситуации в заданиях.

Функциональный прототип по ТЗ Департамента финансов города Москвы («Виртуальный питомец: финансовая грамотность для детей»).

| | |
|---|---|
| Пакет | `app.finni.kids` |
| Платформа | Android 8.0+ (minSdk 26), портрет от 360 dp |
| Сеть / аккаунт | не нужны |
| Реклама / покупки | нет |
| Данные | только на устройстве (SharedPreferences) |
| Веб-демо | https://aliveapps.ru/finni |

## Что умеет ребёнок

- **Питомец** — выбирает вид, цвет, имя и украшение; состояние питомца растёт или падает от решений в игре.
- **План недели** — раскладывает монеты по трём конвертам: нужное / хочется / копилка.
- **Магазин** — покупает нужное и желаемое; каждое действие даёт понятное последствие и отчёт «что изменилось и почему».
- **Копилка и мечта** — копит на цель, видит прогресс по неделям.
- **Задания** — истории, сортировки, расчёты и симуляции по темам финансовой грамотности.
- **Раздел для взрослых** — настройки, демо-режим, сброс тестового профиля (защита простым примером).

Ошибка в игре — не наказание, а учебная ситуация с путём исправления.

## Состав репозитория

Две реализации с **общей игровой логикой и учебным контентом**:

| Папка | Стек | Версия | Назначение |
|---|---|---|---|
| [`finny/`](finny/) | TypeScript · Preact · Vite · Capacitor 8 | 1.0.0 | Веб + Android (WebView), быстрый прототип и демо в браузере |
| [`nativeapp/`](nativeapp/) | Kotlin · Jetpack Compose | 2.0.0 | Полностью нативное Android-приложение |

Нативная сборка ставится поверх веб-версии (тот же `applicationId` и ключ подписи).

```
finny/          веб-версия
  src/domain/   чистая экономика (без UI и хранилища)
  src/content/  JSON: товары, цели, задания, события, словарик
  src/app/      состояние, навигация, сохранение
  src/ui/       экраны и компоненты
  src/platform/ Preferences, звук, кнопка «назад»
  android/      проект Capacitor
  tests/        Vitest (~240 тестов)
  docs/         архитектура, экономика, сборка, соответствие ТЗ

nativeapp/      нативная версия
  app/.../domain/   порт движка на Kotlin
  app/.../content/  загрузка того же JSON из assets
  app/.../ui/       Compose-экраны, тема «Космическое приключение»
  app/src/test/     JUnit (в т.ч. случайные прогоны)
  docs/             архитектура, сравнение с веб-версией
```

## Подробное описание реализации

### Архитектурный принцип

Сервера нет. Вся логика работает на устройстве. Зависимости слоёв односторонние:

```
UI (экраны)  →  App (состояние / навигация)  →  Domain (экономика)  →  Content (JSON)
                      ↓
                 Platform (хранилище, звук)
```

`domain` и `content` **не знают** об интерфейсе и Android API — поэтому экономика покрыта автотестами без эмулятора и браузера.

### Игровой движок

Каждое действие — чистая функция:

```text
(профиль, аргументы) → Outcome
```

- **Успех** — новый профиль (исходный не мутируется) + отчёт: что изменилось, почему и что делать дальше; запись в истории операций.
- **Ошибка** — код (`NOT_ENOUGH`, `CONFIRM_OVER_PLAN`, `PLAN_REQUIRED`…) с объяснением и вариантами выхода.

Подтверждения (снять из копилки, купить «хочется» сверх плана) зашиты в движок: без `confirmed: true` действие отклоняется. Обойти их из UI нельзя — баланс не меняется без объяснения.

Периоды (недели), доход, рост питомца, случайные события и демо-режим тоже живут в domain.

### Учебный контент

Данные в JSON, не в коде:

- каталог товаров и цены;
- цели накопления;
- события недели;
- словарик;
- задания в отдельных файлах (`tasks/*.json`).

Новое задание — новый JSON-файл; код менять не нужно. Контент валидируется при загрузке (веб: `validate.ts`, native: `validateContent`).

### Состояние и сохранение

Единственный путь изменения профиля — `act(...)` в сторе / `Game.act` (native).

- Сохранение с задержкой ~120 мс (серия действий пишется одним разом).
- При сворачивании приложения — немедленная запись.
- Ключ хранилища: Preferences / SharedPreferences (JSON).
- Повреждённые данные не роняют игру: резерв + старт заново; старые поля достраиваются дефолтами.
- Игровой и демо-профили разделены. Резервное копирование Android выключено.

### Интерфейс

Тема **«Космическое приключение»**: тёмный фон, светящиеся монеты, питомец-исследователь.

- Веб: Preact-экраны, SVG-питомец и иконки, CSS.
- Native: Jetpack Compose, Material 3 только как база; питомец собирается из SVG (AndroidSVG) по параметрам вид × цвет × украшение × стадия × выражение.

Окна (подтверждение, отчёт, шторка) — поверх навигации; системная «назад» сначала закрывает окно, затем идёт по стопке маршрутов.

### Доступность

- TalkBack-описания у интерактивных элементов.
- Масштаб текста: обычный / крупный / очень крупный.
- Режим высокого контраста.
- Отключение музыки, звуков и анимаций.
- Цвет не единственный признак состояния.

### Сборки и проверка

| | Веб (`finny/`) | Native (`nativeapp/`) |
|---|---|---|
| Разработка | `npm ci && npm run dev` | Android Studio / `./gradlew assembleDebug` |
| Тесты | `npm test` | `./gradlew testDebugUnitTest` |
| Релиз | `npm run release` → APK/AAB | `./scripts/build-release.sh` |
| На устройстве | `node scripts/device-smoke.mjs` | то же |

Ключ подписи — вне репозитория (`~/.finni-release/`), создаётся `finny/scripts/make-keystore.sh`.

## Быстрый старт (веб)

Нужен Node.js 22+.

```bash
cd finny
npm ci
npm test
npm run dev    # http://localhost:5173 — удобнее в режиме телефона 360×640
```
