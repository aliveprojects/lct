# Финни

Офлайн-приложение финансовой грамотности для детей 7–11 лет: питомец, план недели (нужное / хочется / копилка), магазин, накопления и задания.

Репозиторий ЛЦТ — две реализации с общей игровой логикой и контентом:

| Папка | Стек | Версия |
|---|---|---|
| [`finny/`](finny/) | Preact + Vite + Capacitor (Android) | 1.0.0 |
| [`nativeapp/`](nativeapp/) | Kotlin + Jetpack Compose | 2.0.0 |

Пакет: `app.finni.kids`. Без интернета, аккаунта, рекламы и покупок. Данные только на устройстве.

Веб-демо: https://aliveapps.ru/finni
